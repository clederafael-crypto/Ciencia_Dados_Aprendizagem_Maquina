2. Objetivo da atividade

Nesta atividade, sua equipe deverá analisar um problema real e pensar como uma equipe de Ciência de Dados poderia utilizar dados para compreender a situação e apoiar uma decisão.

O objetivo não é desenvolver um sistema ou modelo de Machine Learning neste momento.

O objetivo é aprender a pensar como um cientista de dados:

«Problema → Dados → Informação → Análise → Decisão → Benefício»

13. Os 5 Vs do Big Data

Analise o problema escolhido pela equipe.

V| Pergunta| Resposta da equipe
Volume| Existe uma grande quantidade de dados?| Sim. O sistema pode armazenar diversas receitas e despesas ao longo do tempo.
Velocidade| Os dados são gerados ou processados rapidamente?| Sim. Os dados podem ser registrados e analisados conforme são inseridos.
Variedade| Existem diferentes tipos ou formatos de dados?| Sim. Existem valores, datas, categorias e formas de pagamento.
Veracidade| Os dados podem apresentar erros ou problemas de qualidade?| Sim. Os dados podem apresentar erros caso sejam inseridos incorretamente pelo usuário.
Valor| Os dados podem gerar algum benefício ou apoiar decisões?| Sim. Os dados podem gerar informações para auxiliar na organização financeira.

Qual dos 5 Vs é mais relevante para o problema?

«Valor.»

Justifique

«O valor é o mais relevante porque os dados financeiros precisam ser transformados em informações úteis. O objetivo é utilizar essas informações para auxiliar o usuário na compreensão da sua situação financeira e na tomada de decisões.»
