# Pré-requisitos

Confirme cada item antes de iniciar a fase 2.

| Nº | Pré-requisito | Por que importa | Atendido? | Observações |
|---|---|---|---|---|
| 1 | Histórico suficiente de escalas registradas no sistema | O efetivo da Banda é pequeno; poucos meses de dados não permitem conclusões confiáveis | Não | |
| 2 | Autorização da Organização Militar para uso dos dados | São dados de militares em ambiente institucional | Não | |
| 3 | Anonimização dos dados pessoais (LGPD) | A LGPD já é citada no TCC; usar identificadores em vez de nomes | Não | |
| 4 | Campo status das escalas preenchido de forma consistente | As métricas de faltas e substituições dependem dele | Não | |

> Valores possíveis em "Atendido?": Sim, Não, Parcial. Só comece o estudo quando os quatro estiverem como Sim.
