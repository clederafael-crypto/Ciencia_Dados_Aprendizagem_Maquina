# Fase 6: Implantação

## Objetivo central

Incorporar formalmente os modelos ao sistema ou usar as descobertas para mudar a estratégia.

## Checklist de execução

- [ ] **Plano de Implementação (arquitetura)**
  - [ ] Painel de equidade no painel administrativo ou script Python agendado
- [ ] **Plano de Monitoramento (obsolescência do modelo)**
  - [ ] Recalcular as métricas mensalmente
  - [ ] Retreinar o modelo quando o efetivo ou as regras do RISG mudarem
- [ ] **Relatório e Apresentação Final**
  - [ ] Resultados para o sargenteante e o comando
  - [ ] Material para a disciplina
- [ ] **Revisão do Projeto (lições aprendidas)**
  - [ ] O que funcionou, o que mudar no próximo ciclo

## Caso prático: MilitarySchedule

**Desenvolvedor do sistema:** Incorpora o painel de equidade ao MilitarySchedule, reaproveitando os scripts Python agendados.

**Banco de dados:** Prepara o banco para novos atributos, como motivo da substituição e agenda de eventos.

**Feedback:** O sargenteante e o efetivo avaliam se o painel torna a distribuição mais transparente.
