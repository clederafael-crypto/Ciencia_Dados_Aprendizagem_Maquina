Big Data refere-se ao uso de grandes volumes de dados para obter informações e identificar padrões. Ele é importante para a Ciência de Dados porque possibilita analisar dados e gerar conhecimentos para apoiar decisões. No Machine Learning, grandes quantidades de dados permitem que os algoritmos aprendam padrões e realizem previsões
